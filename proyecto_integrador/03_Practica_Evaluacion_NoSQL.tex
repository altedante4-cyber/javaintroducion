\section{Servicio Asignado: Sesiones Activas y Caché de Bater\'ia (Servicio C)}

EcoDrive necesita un sistema de sesiones activas y caché de bater\'ia. La aplicaci\'on m\'ovil requiere saber de forma casi instant\'anea qu\'e veh\'iculos est\'an libres y cu\'anta bater\'ia les queda. Se gestionan tokens de sesi\'on temporal que deben expirar autom\'aticamente al finalizar el viaje. Se ha elegido \textbf{Redis} como base de datos Clave-Valor por su latencia de microsegundos, soporte de TTL y operaciones at\'omicas de decremento.

\begin{criterio}
\begin{itemize}
    \item \textbf{CE.a:} Se han identificado las caracter\'isticas de los sistemas NoSQL.
    \item \textbf{CE.b:} Se han evaluado los tipos de bases de datos NoSQL y su adecuaci\'on al caso de uso.
    \item \textbf{CE.c:} Se han identificado los elementos (agregados, claves, nodos, tipos de datos) utilizados en estas bases de datos.
    \item \textbf{CE.d:} Se ha gestionado la informaci\'on utilizando comandos espec\'ificos.
    \item \textbf{CE.e:} Se han utilizado herramientas gr\'aficas para la gesti\'on de las bases de datos.
\end{itemize}
\end{criterio}

\subsection{Entregable 4: Scripts de Redis para Sesiones y Cache (Servicio C)}

A continuacion se presentan los scripts ejecutados en Redis para el Servicio C (Sesiones Activas y Cache de Bateria). Se utiliza la convencion de nomenclatura jerarquica con dos puntos (:), que permite la busqueda por prefijos y organiza visualmente las claves.

\begin{lstlisting}[caption=Creacion de sesion de viaje con expiracion automatica]
// ============================================================
// SCRIPT REDIS - SESIONES Y CACHE DE BATERIA
// Servicio C: Sesiones Activas y Cache de Bateria
// ============================================================

// 1. Crear un registro de sesion de viaje que expire en 60s
//    Nomenclatura: sesion:token:<ID>
SET sesion:token:A7X3K9 "usuario:42|vehiculo:PAT-001|inicio:2025-05-19T08:30:00Z"
EXPIRE sesion:token:A7X3K9 60

// 2. Estructura para nivel de bateria de 3 vehiculos
//    Nomenclatura: vehiculo:<id>:bateria
HSET vehiculo:PAT-001:bateria nivel 85 ultima_actualizacion "2025-05-19T08:30:00Z"
HSET vehiculo:BIC-002:bateria nivel 100 ultima_actualizacion "2025-05-19T08:30:00Z"
HSET vehiculo:COC-003:bateria nivel 72 ultima_actualizacion "2025-05-19T08:30:00Z"

// 3. Simular consumo: decrementar bateria del patinete en 5%
HINCRBY vehiculo:PAT-001:bateria nivel -5
\end{lstlisting}

\begin{lstlisting}[caption=Verificacion de datos en Redis]
// Consultar la sesion (debe responder dentro de 60s)
GET sesion:token:A7X3K9

// Consultar bateria actual del patinete tras el consumo
HGETALL vehiculo:PAT-001:bateria

// Listar todas las claves relacionadas con bateria
KEYS vehiculo:*:bateria

// Verificar el TTL restante de la sesion
TTL sesion:token:A7X3K9
\end{lstlisting}

\subsubsection{Instrucciones para la ejecucion}

Para reproducir los resultados mostrados en las capturas, se deben seguir los siguientes pasos:

\begin{enumerate}
    \item Iniciar el contenedor de Redis: \texttt{docker run -d --name eco-redis -p 6379:6379 redis:7}
    \item Conectarse a redis-cli: \texttt{docker exec -it eco-redis redis-cli}
    \item Ejecutar los scripts del Entregable 4 en orden.
    \item Para Redis Insight: \texttt{docker run -d --name eco-redis-insight -p 5540:5540 --link eco-redis:redis redislabs/redisinsight} y acceder a \texttt{http://localhost:5540}
\end{enumerate}

\section*{Anexo: Redis - Conceptos Clave para el Servicio C}

\subsection*{A1. Redis: M\'as all\'a del Texto (Key-Value avanzado)}
\begin{itemize}
    \item \textbf{HASHES:} No guardes un objeto como un JSON gigante. Usa \texttt{HSET}. Permite editar solo un campo (ej. bajar la bater\'ia un 1\%) sin tener que reescribir todo el veh\'iculo en memoria.
    \item \textbf{TTL (Time To Live):} Fundamental para sesiones. Si no se usa \texttt{EXPIRE}, la memoria se llenar\'a de sesiones de usuarios que ya finalizaron su viaje.
    \item \textbf{Nomenclatura con dos puntos (:):} Permite organizar las claves jer\'arquicamente y buscar por prefijos con \texttt{KEYS}. Ej: \texttt{sesion:token:ABC}, \texttt{vehiculo:id:bateria}.
    \item \textbf{HINCRBY:} Operaci\'on at\'omica para incrementar/decrementar valores num\'ericos dentro de un HASH, ideal para simular consumo de bater\'ia sin condiciones de carrera.
\end{itemize}
